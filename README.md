# Task Management System – Backend API

This is the **Node.js + Express.js** backend for the Task Management System. It provides a secure and structured REST API for managing tasks, authentication, and data persistence using MongoDB.

## 🔗 Frontend Repository

👉 [Click here to view the React frontend](https://github.com/Nandalal97/task-management-fronend)

---

## 📦 Tech Stack

- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT (Authentication)
- Zod (Validation)
- Helmet, XSS-Clean, Rate Limiting (Security)
- dotenv (Environment Config)
